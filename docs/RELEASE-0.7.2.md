## Исправлен запуск Windows-приложения

В 0.7.0–0.7.1 ошибка JavaScript в экране раздельного туннелирования обрывала запуск интерфейса. На экране оставалась надпись «0.1.0», не работали меню и добавление ключей, хотя приложение продолжало жить в трее. Причина была внутри сборки, а не в скачивании старой версии.

- Исправлена ошибка запуска раздельного туннелирования.
- Убрана ложная заглушка версии «0.1.0»; номер берётся из запущенного приложения.
- При ошибке запуска теперь появляется отдельный экран с версией, описанием ошибки, перезагрузкой окна и выходом.
- Исправлена ошибка отображения уведомления о неудачной проверке соединения.
- Исправлено обрезание пути с пробелами при тихой установке и обновлении: новая версия устанавливается в нужную папку.
- Перед сборкой автоматически проверяется синтаксис всех файлов приложения.
- Публикация релиза требует успешного запуска установленного EXE, проверки интерфейса, подключения, смены ключей, передачи данных через Windows TUN и обновления с 0.3.1 с сохранением ключа и настроек.

Установщик ставится поверх предыдущей версии и сохраняет ключи и настройки. Если интерфейс 0.7.1 не реагирует, скачайте установщик 0.7.2 из этого релиза и запустите его вручную.

Сетевые проверки используют отдельные временные серверы. Доступность каждого пользовательского сервера и вход в личный кабинет с реальным аккаунтом отдельно не проверяются.
