# EVA VPN 0.7.1 — Windows

Исправления загрузки обновлений и переключения ключей после 0.7.0.

- Скачивание через сетевой стек Electron учитывает системный прокси Windows.
  Заголовки ожидаются до 20 секунд, пауза без данных ограничена 30 секундами,
  вся загрузка — 10 минутами. До трёх попыток, включая адрес файла через API
  GitHub. Отмена прерывает запрос и запись, ошибки диска завершают операцию.
- Файл сначала пишется в `.part`; после закрытия записи проверяются размер и
  SHA-256. Перед установкой файл проверяется повторно. Редиректы ограничены
  адресами GitHub, имя и архитектура файла выбираются явно.
- Установленная версия обновляется в том же каталоге с `--updated`.
  Portable-версия скачивает portable-файл и заменяет его после закрытия старой
  копии; предыдущий EXE сохраняется рядом для ручного отката.
- Перед установщиком приложение завершает собственное ядро и восстанавливает
  сетевые настройки. Метка обновления принимается только нужной версией.
- EVA больше не завершает все `sing-box.exe` на компьютере. Обычная остановка
  ждёт конкретный дочерний процесс; поиск оставшегося ядра проверяет путь к
  исполняемому файлу и конфигурации EVA.
- Смена ключа отменяет предыдущую попытку и устаревшие автоповторы. Последний
  выбранный ключ применяется и во время подключения; ответ старого процесса
  не сбрасывает состояние нового. Внутренний повторный запуск убран: повтором
  управляет одна очередь приложения.
- Проверки старого соединения не меняют настройки нового туннеля. Исправлено
  затенение функции перевода результатом проверки, из-за которого обработка
  неработающего туннеля завершалась исключением.

## Переход с 0.6.0 / 0.7.0

Если встроенная загрузка зависает, скачайте установщик 0.7.1 и установите
поверх прежней версии в тот же каталог. Удалять приложение и настройки перед
этим не нужно. Если используете portable — закройте прежнюю копию и замените
portable EXE. Исправленный механизм обновления находится в новой версии и
не может изменить уже запущенный загрузчик старой сборки.

## Проверка

По просьбе пользователя приложение, VPN, ядро и тесты не запускались.
Выполнены просмотр исходников и сборка установщика/portable. Работа обновления
и переподключения на пользовательских устройствах остаётся непроверенной.
