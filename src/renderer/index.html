Новое правило

            
            
            
            
            
По одному в строке или через запятую. Домен включает поддомены; путь ссылки не учитывается.

            

            
            
            

            

            

              
              
            

          

          

            
Мои правила 

            
Доменные правила важнее программ и наборов. Более точный поддомен важнее общего домена.

          

          
          
          

          

          
Для видео и приложений могут понадобиться дополнительные домены CDN. Добавьте их в то же правило. Зашифрованный DNS браузера может мешать определению домена.

        

        

          
Эти настройки применяются к адресам без доменного правила.

          

            
            
            
          

          

            

            
            

              
              
            

          

          
Программа опознаётся по имени исполняемого файла без учёта регистра. Если у разных программ одинаковое имя файла, правило действует на обе.

        

        

          
Готовые блокировки и обходы для адресов без доменного правила.
