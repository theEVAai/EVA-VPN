Первый IPA клиента EVA VPN для iPhone и iPad (iOS 16+).

В архиве находятся приложение SwiftUI, VPN-расширение NetworkExtension и ядро
sing-box 1.13.12. Поддерживаются импорт ключей и HTTPS-подписок, правила
Direct / VPN / Block и настройки соединения. Маршруты через несколько ключей
из Windows 0.7.0 в эту iOS-версию пока не перенесены.

Файл `EVA-VPN-0.6.0-iOS-unsigned.ipa` собран для настоящего устройства arm64.
Он не подписан сертификатом Apple и не содержит provisioning profiles.
Перед установкой необходима повторная подпись приложения и расширения с правами
`packet-tunnel-provider` и общей App Group `group.ai.theeva.vpn`.
Обычная бесплатная подпись без этих прав не позволяет запустить VPN.

По просьбе пользователя выполнялась только сборка. Приложение, VPN,
симулятор и тесты не запускались; работа на устройстве не проверена.
